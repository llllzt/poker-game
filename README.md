# 德州扑克 · 内部娱乐局

小范围（≤10 人）内部玩的德州扑克，记分娱乐局模式。两种运行模式，**前端自动探测、无需手动切换**：

- **局域网服务器模式**（推荐线下同 WiFi 用手机玩）：在一台电脑运行 `server.js`，它即是发牌服务器，手机连其局域网地址即可，**完全不依赖外网**。
- **P2P 模式**（线上 / CloudStudio）：房主浏览器充当权威节点，其余人经 PeerJS 直连。

## 玩法
- 每人初始 1000 筹码，小盲 10 / 大盲 20。
- 完整支持：盲注、翻牌/转牌/河牌、过牌/跟注/加注/弃牌、**全下与边池**、摊牌比牌自动结算。
- 房主点击「开始游戏」发牌；每手结束房主点「下一手」继续；「重置筹码」清空重开。
- **昵称**：加入前必须填写（避免「玩家37」认不清）；进局后点自己的座位卡可随时改名。
- **实时排名**：牌桌上每位玩家按筹码多少显示名次徽标（①②③…），一眼看清谁领先。

## 场景一：线下同 WiFi，手机开玩（最常用）

1. 找一台连着该 WiFi 的电脑（笔记本/台式均可），进入本目录运行：
   ```bash
   node server.js
   ```
   启动后会打印类似：
   ```
   同 WiFi 手机: http://192.168.1.23:3000   或   http://192.168.x.x:3000
   ```
2. 把上面「同 WiFi 手机」的地址发给朋友，**他们在手机浏览器打开即可**（建议横屏）。
3. 进入大厅后：创建房间者填「房间名称」点「创建房间」；加入者**无需输房间码**，直接在大厅里看到房间名、点击即可加入。房主点「开始游戏」发牌。
4. 关闭这台电脑的 `server.js` 窗口即结束游戏（房间数据在内存中，不落盘）。

> 房间目录（/api/rooms）仅对连上同一局域网的人可见，天然私密；全员离开后房间自动从目录清除。

> 零依赖：仅需 Node.js（内置模块，无需 `npm install`）。全程内网，断网也能玩。

## 场景二：线上 / CloudStudio 一键部署

1. 将本目录整体部署到 CloudStudio 静态托管，获得 https 链接发给朋友，点开即玩。
2. 因云端为纯静态（无服务器），大厅自动回退到 P2P 模式：一人「创建房间」生成房间码，其余人输入房间码「加入」。

> 该模式下实时连接依赖 PeerJS 公共信令（需联网）；「免输码目录」仅在局域网服务器模式下可用。

## 目录结构
- `engine.js` —— 扑克核心引擎（发牌、牌型评估、边池、下注状态机），浏览器/Node 双兼容。
- `net.js` —— 统一网络层：自动探测局域网服务器（SSE+fetch），失败回退 P2P（PeerJS，房主权威）。
- `app.js` / `index.html` / `style.css` —— 前端界面与交互（含手机横屏适配与竖屏提示）。
- `server.js` —— 零依赖局域网游戏服务器（静态托管 + 权威节点 + SSE 实时推送）。
- `test/engine.test.js` —— 引擎单元测试与随机对局模拟。
- `test/server.test.js` —— 局域网服务器端到端测试。

## 测试
```bash
node test/engine.test.js     # 牌型大小、平局、边池分配、200 手随机模拟筹码守恒
node test/server.test.js     # 局域网服务器：健康探测/加入/开始/完整一手牌/守恒/SSE 推送
```

## 注意事项
- **局域网模式**：运行 `server.js` 的那台电脑就是权威节点，不要中途关闭；它掉线则本局结束（玩家可在其重启后用房主同一浏览器重连）。
- **P2P 模式**：房主浏览器是权威节点，房主不要中途关闭页面；房主掉线则本局结束。
- 两种模式均无持久化，刷新页面会重置；房主可用同一浏览器重连保留座位（玩家 id 存于 localStorage）。
- 手机端已做横屏适配；竖屏会提示「请横屏」，可点「仍用竖屏」继续使用。
